从「能看见插件」到「能直接问」：这一版把右侧的咨询框换成会看你工作的推荐块，把咨询并进搜索框，顺手修掉了真机上试出来的几处毛病。

## 新增

- **猜你喜欢（新块）**：替换右侧「咨询」。只读扫本机（工作区文件、任务看板、会话标题，可选勾 1–3 个会话正文）→ 结构摘要（默认约 3 千字、零网络）→ 当前 DSH 模型出「你缺什么能力」→ 拿英文关键词去全量目录检索；**只显示真存在的插件**，命中不了的需求直接不出现；最多 5 个命中、一条需求最多 2 行、跨需求去重；行尾「不感兴趣」记在 localStorage、同一条目不再出现；「换一批」重新扫
- **猜你喜欢改用榜单同款卡片**：`.dsk-col` + 标题栏 + 每行都是榜单那套行（可点、可关注、可复制安装命令），不再是一套自造的小列表
- **搜索框改造**：右侧「咨询」并进搜索框——普通词直接筛，像问题的词多给一个「问模型」；点常用词（这周有什么值得装的 / 能干什么 / 有什么坑 / 和我装的重复吗 / 有没有替代品）或按钮就在面板内切到咨询页，← 返回后搜索词和列表都还在；目录里搜不到时给一条「把这个词问给模型」

## 改

- **全量屏与 N 屏的中文**：翻译改成跟着**画出来的行**走——行一出现就排队，攒 15 条问一次宿主（宿主带磁盘缓存），翻到第几页翻第几页，不会为了三千行一次问光；失败两次不再重问
- **点击去哪修好了**：全量 npm 行此前没有可点的链接（宿主那条数据没有 url，另一处给的是 `git+https://…`，浏览器不认）。现在 npm 行统一指向 `npmjs.com/package/<包名>`，GitHub 行去掉 `git+` 与 `.git` 还原成网页地址
- **官方仓库只留在底部那张卡**：`deepseek-ai` 的仓库和 `@deepseek-ai/` 包不再出现在合并屏三列、N 屏三列、推荐池、远端搜索里
- **G/N 都有时点哪边**：主链接跟着列走（G 列去 GitHub、N 列去 npm），两边都有时行尾多两个小标 `G` `N`；N 屏里这类包打 `G∩N` 角标
- **「我关注的」不再被挤掉，还能自己变高**：右栏「猜你喜欢」原来按内容高度抢位（`flex:1 1 auto`），十组需求一多就把下面的「我关注的」压到零高；现在「猜你喜欢」只吃剩余高度（`flex:1 1 0`），「我关注的」按内容长、上限 66%、至少 112px；上沿加了一道把手，往上拖最高到栏高八成，双击按内容还原，拖过的高度记在 `localStorage`（`ddp.watchH`），关掉再开还在
- **README**：去掉对不齐的 ASCII 界面图，改成「顶部状态 + 四栏表格」（原本是 0.2.1 的内容，一并进这一版）

## 升级方式

```
dsh plugin install dsh-daily-push@0.3.0
```

0.2.x 的设置（关注列表、令牌、各列翻到第几页）都在原地，不需要重配。

## 已知限制

- 没有完整英文界面，英文行靠宿主模型的批量翻译（跟着画出来的行走，失败两次不再重问）
- GitHub 未登录时每个查询最多只能拿到 1000 条里的前 400 条；面板 ⚙ 里填令牌可到 1000
- 面板宽度小于约 900px 时四列会挤，暂时没有窄屏版式
